# 修行紀錄（xiuxing）

個人自用的修行紀錄 PWA：念經與整套功課（四眾佛子共勉語、大悲咒、心經、普門品、普賢十大願王、三皈依、回向偈、四弘誓願、普賢警眾偈）、佛號計數、打坐計時（引磬、溪流水聲）、抄經（直書描紅、觸控筆、我的抄經本）、心情日記（文字＋語音）、迴向、雲端同步（自己的 Google 雲端硬碟）。資料只存在使用者自己的瀏覽器與自己的雲端硬碟，本 repo 不含任何個人資料。
